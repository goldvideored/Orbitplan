# Orbitplan

Командная PvP/PvE стратегия в космосе. Базы на спутниках газового гиганта, производство на конвейерах, задача — уничтожить вражеское ядро.

Движок: **Godot 4.3+** (GDScript).

## Что уже есть

- **Круглая планета** радиусом 84 м из 17 642 клеток-многоугольников (шестиугольники + 12 пятиугольников). Каждая клетка — зона постройки
- **Рельеф террасами**: 5 уровней высоты, верхний (скалы) — строить нельзя. Руда — рыжие клетки
- Гравитация к центру планеты, планету можно обойти кругом. Ядра команд на противоположных сторонах
- Персонаж от первого лица, бластер, PvP. Орбитальная камера по Tab
- Экономика: 8 видов залежей, переработка, энергосеть, трубы для воды (см. ниже)
- Вражеские волны выключены до этапа с ботами
- Сеть: хост, клиент, выделенный сервер без графики. Сервер считает всё, клиенты только рисуют

## Запуск

1. Скачать Godot 4.3+ с godotengine.org
2. Godot → Import → выбрать `project.godot` → Run (F5)
3. «Создать игру (хост)»

Проверить мультиплеер на одном ПК: Debug → Customize Run Instances → 2 экземпляра. Один хостит, второй подключается к `127.0.0.1`.

### Выделенный сервер

```
godot --headless --path . -- --server --port=7777
```

или `run_server.bat` / `run_server.sh`. Порт **7777/UDP** должен быть открыт (проброс на роутере или фаервол VPS).

## Управление

По умолчанию ты персонаж от первого лица. Строишь на клетку, куда смотришь (до 12 м). Конвейер направляется на соседнюю клетку по взгляду, R поворачивает на одну грань.

| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Space / Shift | прыжок (гравитация низкая) / бег |
| **Z (держать)** | круговое меню: мышь — группа, колесо — подтип, отпустил — выбрал |
| 1–5 | быстрый выбор группы (повторное нажатие листает группу) |
| колесо | листать все постройки |
| 6 | бластер (ЛКМ — огонь, бьёт юнитов и вражеских игроков) |
| R | повернуть постройку |
| ЛКМ (можно тянуть) | строить |
| ПКМ | снести (возврат половины цены) |
| Tab | орбитальная камера ⇄ от первого лица (на орбите WASD крутит планету) |
| F | фонарик |
| Esc | отпустить курсор |

Вражеские юниты атакуют и персонажа. После смерти — респаун у ядра через 5 с.

## Небо и свет

Система отсчёта привязана к планете (как в KSP): планета вращается вокруг оси с наклоном 15° (сутки — 4 мин) и летит по орбите вокруг газового гиганта (оборот — 16 мин). Время считает сервер, у всех одинаковое.

Свет квантуется на **16 уровней** (шейдер `shaders/lit16.gdshader`):
- солнце — до 16, маленькая яркая точка в небе
- отражённый свет гиганта — до 4, зависит от его фазы (как у Луны)
- фонарик — до 12
- **0 — полная темнота**, никакой «подсветки из ниоткуда»

Когда гигант закрывает солнце — затмение. Светящиеся части (ядро, руда на лентах, трассеры) видны и в темноте.

## Экономика

**Сырую руду ядро не принимает** — сначала переработка.

| Залежь | Чем добывать | Переработка | Продукт |
|---|---|---|---|
| Угольная руда | Бур I+ | Дробилка | Уголь |
| Медная руда | Бур I+ | Плавильня | Медь |
| Железная руда | Бур I+ | Плавильня | Железо |
| Кварцевый песок | Бур I+ | Плавильня | Кремний |
| Лёд (полюса, низины) | Бур I+ | Растопитель | Вода — **только по трубам** |
| Свинцовая руда *(редкая)* | Бур II+ | Плавильня | Свинец |
| Урановая руда *(редкая)* | Бур II+ | Центрифуга (4 → 1) | Уран |
| Гелиевый реголит *(редкий)* | Бур II+ | Синтезатор + вода | Топливо He-3 |

**Буры:** I — медленный, без энергии; II — быстрый, 50 энергии; III — очень быстрый, 150 энергии + вода.

**Размеры:** базовые постройки — 1 клетка, второго уровня — 3 (треугольник), третьего — 9 (ромб 3×3). Бур добывает со всех рудных клеток под собой, скорость пропорциональна их доле.

**Энергия:** генератор питает клетки в 4 кольцах вокруг себя (~61 клетка). Перекрывающиеся зоны сливаются в одну сеть; машина вне зоны не работает. Если в сети не хватает энергии — все её машины работают медленнее. При выборе генератора его зона подсвечивается.
- Солнечная панель — до 100, умножается на уровень света (ночью и в затмение 0)
- Угольная ТЭС — 500, жжёт уголь
- АЭС — 1000, нужны уран и вода

Конвейеры возят только твёрдое, трубы — только воду. Машины отдают продукт в любую клетку вокруг своего контура: конвейер, трубу, другую машину или ядро. Наведи прицел на постройку — увидишь её состояние: что внутри, прогресс, энергию и почему стоит.

## Код

- `scripts/defs.gd` — все константы, предметы, рецепты и баланс
- `scripts/sky.gd` — небесная механика (общая для сервера и клиентов)
- `scripts/net.gd` — сеть (автозагрузка `Net`)
- `scripts/planet.gd` — генерация сферы из многоугольников, рельеф, руда, меш
- `scripts/player.gd` — персонаж с гравитацией к центру планеты
- `scripts/world.gd` — симуляция (сервер) + отрисовка и ввод (клиент)
- `scripts/main.gd` — меню
