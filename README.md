# Orbitplan

**Командная космическая стратегия с видом от первого лица.** Пять планет на орбитах вокруг газового гиганта, базы из шестиугольных клеток, производственные цепочки на конвейерах, ракеты с честной орбитальной механикой, армии юнитов и захват баз. PvP до 5×5 (синие против красных) и PvE против нейтральных баз.

Движок — **Godot 4.3+** (проверено на 4.7.2), язык — GDScript. Ни одного файла-текстуры: вся графика — пиксель-арт, который рисуют шейдеры.

---

## Коротко об игре

- **Звёздная система:** газовый гигант с кольцами и 5 планет на круговых орбитах. Планеты названы в честь экзопланет, открытых телескопом «Кеплер»: Kepler-22b, Kepler-186f, Kepler-452b, Kepler-62f, Kepler-442b. Синие стартуют на Kepler-186f, красные — на Kepler-62f (2-я и 4-я планеты от гиганта, между ними нейтральная Kepler-452b), на каждой планете есть нейтральная база с обороной.
- **Круглые планеты:** каждая планета — сфера из клеток-многоугольников (шестиугольники + 12 пятиугольников, клетка ~2 м), с рельефом террасами. Планеты разные: малые (радиус 50 м, гравитация ×0.5), обычные (84 м) и большая (168 м, ×2). Гравитация к центру, планету можно обойти кругом.
- **От первого лица:** ты космонавт, строишь руками, в руке — выбранная постройка или бластер. По Tab — вид сверху для командования армией.
- **Экономика:** 8 видов руды жилами, переработка (сырьё в ядро не принимается), энергосети, вода по трубам, роверы-курьеры.
- **Космос:** стартовая площадка собирает разведчика или транспорт. Топливо считается в Δv по формуле Циолковского, полёт — по сферам влияния, как в KSP: выход на орбиту, перелёт к соседней планете, посадка. Навбол, автопилот ориентации, карта с прогнозом траектории.
- **Война:** три типа юнитов, четыре типа турелей с баллистикой, ПВО, заборы, ремонт. Захват баз: разрушил чужое ядро — оно стало нейтральным — удержал его 15 с — база твоя. Проигрывает команда, у которой не осталось ни одного ядра.
- **Свет на 16 уровней:** солнце, фазы гиганта, затмения, лампы и фонари. При нуле — абсолютная темнота; лампы можно погасить для маскировки.
- **Сеть:** хост, клиенты и выделенный сервер без графики. Сервер считает всю игру, клиенты только рисуют.

## Запуск

1. Скачать **Godot 4.3+** с [godotengine.org](https://godotengine.org).
2. Godot → **Import** → выбрать `project.godot` → **Import & Edit** → **F5**.
3. Главное меню: на фоне справа — война на планете (синие и красные занимают по 40% поверхности, в нейтральной полосе дерутся юниты и рвутся снаряды), слева внизу с маленькой планеты взлетает разведчик, облетает её и садится обратно. Пункты:
   - **Локальная игра** — в разработке (заглушка);
   - **Локальный мультиплеер** — создать игру (хост) или подключиться по IP и порту;
   - **Список серверов** — в разработке (заглушка);
   - **Креатив** — одиночная игра без сервера (порт не открывается): постройки бесплатны, боеприпасы бесконечны; креатив с друзьями — `--creative` на выделенном сервере;
   - **Выход**.

**Мультиплеер на одном компьютере:** Отладка → Настроить запуск экземпляров → 2 экземпляра. Один хостит, второй подключается к `127.0.0.1`. Игроки распределяются по командам по очереди.

**Через интернет:** открыть порт **7777/UDP** (проброс на роутере или фаервол VPS).

**Выделенный сервер без графики:**

```
godot --headless --path . -- --server --port=7777
```

или `run_server.bat` / `run_server.sh` (креатив: `EXTRA=--creative ./run_server.sh`).

> После обновления проекта делай **Проект → Перезагрузить текущий проект**: шейдеры используют глобальные параметры из `project.godot`, без перезагрузки редактор их не подхватит.

## Управление

Полная справка в игре — клавиша **H**. Вся информация — на панели справа: здоровье, свет (16 делений), энергия, базы, склад значками с полосками заполнения, юниты/лимит, цена того, что в руках (красным — не хватает), а карточка постройки под прицелом (состояние, прочность, прогресс, что внутри) — слева от прицела. В корабле там же топливо, Δv, корпус, груз, высота, скорость, апоцентр и перицентр.

### Пешком (от первого лица)

| Клавиша | Действие |
|---|---|
| WASD, Space, Shift | ходьба, прыжок (гравитация слабая), бег |
| **Z (держать)** | круговое меню построек: мышь — группа, колесо — подтип |
| 1–7 / колесо | быстрый выбор группы / листать постройки; 8 — бластер |
| ЛКМ (можно тянуть) / ПКМ | строить / снести — только рядом с собой, до 12 м |
| R | повернуть постройку (конвейер смотрит по взгляду, R — на грань дальше; завод выдаёт продукт в эту сторону) |
| **U** | модернизировать свой завод (до ур. 3) |
| **E** | сесть в корабль; лампа — вкл/выкл (**Shift+E** — все лампы на планете) |
| **E (держать)** на постройке | точка выгрузки — груз, сборщик — тип юнита, площадка — тип корабля |
| F | фонарик |
| Tab | вид сверху ⇄ от первого лица |
| Esc | отпустить курсор |

**Гибель:** возрождение через 10 с. Первые 5 с можно выбрать, у какой своей базы возродиться (щелчок по кнопке или цифра 1–9) — в том числе на другой планете. Не выбрал — возродишься у ближайшей к месту гибели базы (на той же планете, иначе у главной).

| Клавиша | Действие |

## Экономика

**Сырую руду ядро не принимает — сначала переработка.** Склад — до 500 каждого ресурса; принимает любое своё ядро, включая захваченные. При переполнении лишнее сжигается (у ядра горит огонь), лента не встаёт. Руда лежит жилами, у каждой базы есть стартовые жилы меди, железа, угля и кварца.

| Залежь | Бур | Переработка | Продукт |
|---|---|---|---|
| Угольная руда | I+ | Дробилка | Уголь |
| Медная / железная руда | I+ | Плавильня | Медь / Железо |
| Кварцевый песок | I+ | Плавильня | Кремний |
| Лёд (полюса, низины) | I+ | Растопитель | Вода — только по трубам |
| Свинцовая руда *(редкая)* | II+ | Плавильня | Свинец |
| Урановая руда *(редкая)* | II+ | Центрифуга (4 → 1) | Уран |
| Гелиевый реголит *(редкий)* | II+ | Синтезатор + вода | Топливо He-3 |
| Залежь материи *(малые планеты, редко на большой)* | только III | — (бур сразу выдаёт) | Уникальная материя |
| — | — | Завод микросхем | Микросхема (кремний + медь) |
| — | — | Плавильня | **Сплав Pb-U** (2 свинца + 1 уран) — нужен для построек 3 тира и модернизации до 3 уровня |

- **Редкие породы** (свинец, уран, гелий) добываются в 5 раз медленнее обычных.
- **Буры:** I — тренога с лебёдкой, медленный, без энергии; II — платформа на сваях с мотором, быстрый, 50 энергии; III — буровая вышка с талевым блоком, очень быстрый, 150 энергии и вода.
- **Всё анимировано:** буры крутят штанги и ходят вверх-вниз, дробилка крутит валки, центрифуга — ротор, у ТЭС и плавильни дым из труб, у растопителя и АЭС пар, солнечные панели поворачиваются за солнцем, кран точки погрузки раскачивает ящик, у ядра вращается кристалл. Простаивающая постройка замирает, на нехватке энергии работает вполсилы. Бур добывает со всех рудных клеток под собой.
- **Размеры построек:** базовые — 1 клетка, второго уровня — 3 (треугольник), третьего — 9 (ромб 3×3).
- **Энергия:** солнечная панель (до 100, зависит от света — ночью ноль), угольная ТЭС (500), АЭС (1000, уран и вода). **Аккумулятор** копит излишек сети (до 5000, 400 в секунду) и отдаёт его при нехватке — днём заряжается от панелей, ночью кормит сеть.
- **Машины впритык:** бур, поставленный вплотную к заводу, отдаёт руду прямо в него; так же завод → завод, центрифуга → АЭС, без конвейера. Генератор питает 4 кольца клеток вокруг себя, **энергостолбы** цепочкой тянут сеть дальше. Не хватает энергии — все машины сети работают медленнее.
- **Сортировщик** — конвейер, который берёт на вход только один выбранный груз (держи E — выбрать, над лентой арка со значком).
- **Ленты:** конвейеры — твёрдое, трубы — вода и топливо He-3 (по конвейеру топливо не идёт). Разветвитель, перекрёсток и мост работают с обоими. Лента крутится, только когда по ней что-то едет.
- **Курьеры:** точка погрузки принимает грузы с конвейеров, курьер развозит до 25 единиц по точкам выгрузки, которые принимают нужный груз.
- **Заправщики:** заправочная станция принимает топливо He-3 по трубам, заправщик (машина с цистерной) везёт до 20 единиц на стартовые площадки и точки выгрузки с фильтром «топливо».
- Курьеры и заправщики **уничтожаемы** (150 прочности: бластер, турели) — новый выезжает со своей базы через 1 мин. Ночью у них и у юнитов горят фары.
- **Стройка и снос не мгновенные:** конвейер — 0.4 с, обычная постройка — 2.5 с, на 3 клетки — 6 с, на 9 клеток — 14 с, АЭС, артиллерия и площадка — 20 с. Постройка растёт из земли внутри каркаса цвета команды, к ней тянется луч из руки строителя. Снос идёт столько же (оранжевый каркас); ресурсы возвращаются в конце: половина цены, а если постройку не достроили — вся. Пока идёт стройка или снос, постройка не работает.
- **Соединения:** конвейеры стыкуются с соседями (повороты и слияния, у ленты бегут полосы, есть борта и ролики) и с машинами — заходят в приёмный короб того, во что смотрят, и тянутся от буров и заводов, которые в них выдают; трубы — так же. Разветвитель — ступица с вращающимся распределителем, перекрёсток — крестовина с мостиком, мост — пандус, опора и лента по воздуху до дальнего моста; заборы срастаются в сплошную стену (и примыкают к турелям), энергостолбы соединяются проводами.
- **Заводы выдают продукт только вперёд** — в сторону, куда повёрнуты при постройке (лоток со стрелкой спереди). Принимают сырьё со всех сторон.
- **Модернизация** (U на своём заводе: плавильня, дробилка, растопитель, центрифуга, синтезатор, завод микросхем, сборщик): уровень 2 — скорость ×1.6, уровень 3 — ×2.3, расход энергии растёт (×1.5 / ×2.2). Цена: стоимость постройки ×1 / ×2 плюс микросхемы; на 3 уровень — ещё сплав Pb-U (10, у больших заводов 20). Уровень видно по золотым меткам на корпусе.
- **Огонёк над постройкой:** зелёный — работает, жёлтый — мало энергии, красный — стоит, серый — ждёт. Наведи прицел — увидишь, в чём дело.

## Космос

**Стартовая площадка** (9 клеток) собирает корабли и заправляет их топливом He-3 с конвейера.

| | Разведчик | Транспорт |
|---|---|---|
| Экипаж / груз | 1 игрок | 1 игрок + 12 мест (танк и дрон — 1, мех — 4) |
| Бак / Δv | 24 ед. He-3 / ~185 м/с | 48 ед. / ~160 м/с |
| Прочность | 300 | 800 |

**Бюджет Δv** (проверен симуляцией): выход на орбиту ~40 м/с, перелёт к соседней планете ~17 м/с, посадка ~30 м/с.

**Как летать:** полсекунды вертикально, наклон ~40°, поднять апоцентр до 20–40 м, выключить тягу, у апоцентра скруглить орбиту. Посадка мягче 10 м/с; ниже 80 м сам включается посадочный фонарь, ниже 60 м автопилот разворачивает «против движения».

**Помощник перелёта (T):** выбираешь планету-цель — считается самый экономный перелёт (по Гоману): через сколько секунд окно, сколько Δv на разгон, сколько лететь и сколько нужно на посадку, хватит ли топлива. На навболе оранжевый ◆ — куда жечь, в панели — через сколько секунд скорость корабля совпадёт с этим направлением. На карте системы — эллипс перелёта и где будет цель в момент прилёта. Когда прогноз траектории показывает перехват цели — пишет «ПЕРЕХВАТ ЕСТЬ». Управляешь сам.

**Космический курьер** (постройка «Космопорт курьера» в группе «Космос»): один на команду, летает между своими космопортами сам. В порту выгружает привезённое (порт выдаёт его на конвейеры вокруг — удобно забирать сортировщиками), догружает до 100 единиц груза с конвейеров и заправляется топливом по трубе. С полным баком (30) ждёт 1 мин и улетает: в порт на планете, которую назначили (держи E на космопорте), а если цели нет — обратно, откуда прилетел. Перелёт вдвое быстрее, чем по Гоману; на карте системы курьер — метка ◆. Разрушили порт, где он стоял или куда летел, — курьер потерян, новый через 1 мин.

**Навбол, компас и карта:** навбол — шар-авиагоризонт с маркерами (по движению, против, нормаль, радиально); компас — лента курса; карта (M) следит за ракетой и показывает прогноз траектории, орбиты планет (цветные ленты), сферы влияния, апоцентр и перицентр, точку встречи с соседней планетой.

| Планета | Орбита | Радиус | Гравитация | Сфера притяжения | Особенности |
|---|---|---|---|---|---|
| Kepler-22b | 1700 м | 50 м | ×0.5 | 140 м | малая, зеленоватая; жгучие красные клетки (жгут, искрят); уникальная материя |
| Kepler-186f (синие) | 2400 м | 84 м | ×1 | 331 м | обычная |
| Kepler-452b | 3300 м | 168 м | ×2 | 550 м | большая, желтоватая, с атмосферой; все ресурсы, но редко |
| Kepler-62f (красные) | 4500 м | 84 м | ×1 | 620 м | обычная |
| Kepler-442b | 6000 м | 50 м | ×0.5 | 420 м | малая, зеленоватая; жгучие клетки; уникальная материя |

## Война

### Юниты

| | Мини-танк | Дрон-камикадзе | Боевой мех |
|---|---|---|---|
| Вид | на гусеницах (траки бегут) | 4 винта, парит | паук на 8 ногах (шагает) |
| Прочность | 120 | 30 | 1500 |
| Скорость | 3 м/с | 12 м/с, летает | 1.8 м/с |
| Оружие | 5 урона/с на 5 клеток | таран: −25% прочности цели | 45 урона/с на 10 клеток |
| Цена | 8 железа, 4 меди | 6 меди, 4 кремния, 1 микросхема | 150 железа, 50 свинца, 40 кремния, 25 микросхем |
| Лимит | 20 на ядро | 10 на ядро | 3 на ядро |

Сборщик ничего не делает, пока не выбран тип юнита (держи E). Ресурсы берёт только с конвейеров (не со склада базы, даже в креативе). Собирает на площадке рядом с собой (со стороны, куда он повёрнут): юнит растёт снизу вверх в светящемся каркасе, а робот-рука на крыше сборщика водит по нему лазером. Готовый юнит выходит с этой площадки. **Лимит умножается на число ядер команды** — захват баз увеличивает армию. Поведение: агрессия, охрана точки, стоять.

### Оборона

| | Размер | Дальность | Боеприпас | Особенность |
|---|---|---|---|---|
| Лазерная турель | 1 | 6 клеток | не нужен | мгновенный луч |
| Пулемётная турель | 3 | 10 клеток | медь | пули с баллистикой |
| Артиллерия | 9 | 50 клеток | свинец или уран | навесом, взрыв 10 клеток; уран облучает |
| ПВО | 3 | 90 м | 3 любых ресурса на выстрел, уран облучает | только по летающим, с упреждением; выстрел раз в 1.6 с, с водой чаще |

Снаряды летят физически, с гравитацией к центру планеты; турель численно подбирает угол с учётом кривизны планеты. Башни поворачиваются к цели. Ещё есть **заборы** (не перепрыгнуть, наземные юниты ломают), **ремонтная башня** (чинит постройки) и **ремонтная станция** (чинит юнитов).

### Базы и захват

- **Нейтральная база** на каждой планете: ядро, 4 лазерные и 2 пулемётные турели. Захват — стоять у ядра 15 с, пока рядом нет других команд; при захвате нейтральная оборона исчезает.
- **Вражеское ядро** не взрывается: разрушенное, оно становится нейтральным, дальше его захватывают.
- Вместе с ядром к новому хозяину переходят постройки в радиусе 30 м.
- **Тревоги:** пока вражеский корабль летает в сфере притяжения планеты, где твоя база или ты сам, сверху мигает красный баннер «ВНИМАНИЕ! ПРОТИВНИК В ЗОНЕ ПРИТЯЖЕНИЯ». Ещё — строки тревог: корабль вошёл в атмосферу, постройка разрушена на любой планете (с меткой ⚠ на карте системы).

## Как устроено

- **Сервер считает всё**, клиенты присылают команды и рисуют снапшоты. Каждый клиент получает данные только своей планеты.
- **Одна сетка — пять планет:** все планеты — клоны одной геометрии, клетка определяется парой (планета, номер клетки).
- **Небесная механика** (`sky.gd`) одинакова на сервере и клиентах: система координат привязана к планете, вращение и орбиты считаются из общего времени сервера.
- **Свет** — шейдерный: `light16.gdshaderinc` складывает солнце, гигант, фонари и до 128 ламп/свечений построек и квантует результат на 16 уровней.

### Файлы

| Файл | Что внутри |
|---|---|
| `scripts/defs.gd` | все константы: предметы, постройки, рецепты, юниты, корабли, баланс |
| `scripts/world.gd` | симуляция на сервере, отрисовка и ввод на клиенте |
| `scripts/net.gd` | сеть: хост, клиент, выделенный сервер (автозагрузка `Net`) |
| `scripts/planet.gd` | сфера из многоугольников, рельеф, жилы руды, меши |
| `scripts/sky.gd` | орбиты планет, сферы влияния, небо над каждой планетой |
| `scripts/player.gd` | космонавт с гравитацией к центру планеты |
| `scripts/ship.gd` | полёт корабля, дроссель, автопилот, переходы между сферами влияния |
| `scripts/navball.gd`, `compass.gd` | навбол и компас корабля |
| `scripts/radial_menu.gd` | круговые меню |
| `scripts/icons.gd` | пиксельные значки предметов (рисуются кодом) |
| `scripts/main.gd` | главное меню (панель выбора) |
| `scripts/menu_bg.gd` | фон меню: война на планете и полёт разведчика |
| `shaders/` | весь пиксель-арт и свет: поверхность, постройки, юниты, гигант, кольца, небо, навбол |
